# Hosiery by Si

Liquid-glass Shopify theme. Orders go to WhatsApp only.

## Install

1. Download [hosiery-by-si-theme.zip](https://github.com/naeemcollections/hosiery-by-si/releases/download/v1.1.1/hosiery-by-si-theme.zip)
2. Shopify Admin → Online Store → Themes → Add theme → Upload zip
3. Theme settings → Store → put your WhatsApp number (country code, digits only, example `923001234567`)
4. Edit banners, announcement bar, and Hot deals in the theme editor

Sample products are already on the homepage. To use real Shopify products, open a section and pick a collection.
